# 洛克王国·世界 — 战斗机制规则手册

本手册是《洛克王国：世界》(2026-03-26 上线，腾讯魔方) 的权威战斗机制参考。
涉及机制、数值、公式的问题，一律以本手册为准，不要用其他宝可梦类游戏的常识推断。

---

## 零、反直觉要点（最高优先级，容易答错的地方）

以下条目与宝可梦等同类游戏**不同**，回答时必须严格遵守：

| 项目 | 本作规则 | 常见错误认知 |
|------|----------|--------------|
| 属性克制叠加 | **加算**：双克制 = 1+1+1 = **3 倍** | 乘算 2×2=4 倍 |
| 本系加成 STAB | **1.25** | 1.5 |
| 伤害波动 | **不存在**，伤害完全确定（仅 floor 取整） | 85%~100% 随机 |
| 暴击 | **不存在** | 有暴击率 |
| 等级对伤害的影响 | **无**，等级不参与伤害计算 | 等级进公式 |
| 能力等级（强化/弱化等级） | **不存在**。网传 `1+N×0.5`、`1+N×0.1` 公式来自旧版页游，不适用本作 | 有 ±6 级能力等级 |
| PP | **不存在**，改为能量消耗制 | 每技能有 PP |
| 普通攻击 | **不存在**，一切行动靠技能 | 有普攻 |
| 硬控（麻醉/睡眠/冰冻跳回合） | **不存在**，冻结改为血量阈值判定 | 跳过回合 |
| 胜负判定 | 魔力值归零即败，不取决于精灵是否全灭 | 精灵全灭才败 |

增益/减益全部通过**印记、特性、异常状态、技能效果**实现，没有统一的能力等级系统。

## 一、属性克制

18 种属性：普通、草、火、水、光、地、冰、龙、电、幻、毒、虫、翼、恶、萌、幽灵、武、机械。

（官方部分文案写作「16 属性」，指的是不含神属性分支的说法；实际克制矩阵为 18×18。）

- 克制倍率取值：**0**（免疫）/ **0.5**（抵抗）/ **1**（正常）/ **2**（克制）
- **多重克制为加算**：双属性同时被克制 = 1 + 1 + 1 = **3 倍**
- 完整 18×18 矩阵不在本手册内，需查具体倍率时调用克制关系查询工具

特殊克制关系：

| 关系 | 内容 |
|------|------|
| 基础三角 | 水 → 火 → 草 → 水 |
| 互克体系 | 光 ↔ 恶 ↔ 幽灵（三者互相克制） |

## 二、精灵属性与养成

### 2.1 种族值

6 项种族值：HP、物攻(ATK)、物防(DEF)、魔攻(SPA)、魔防(SPD)、速度(SPE)。
每只精灵有 1~2 个属性（主属性 + 可选副属性），并带 1 条特性文本。

### 2.2 实际属性计算公式

```
个体值范围: 0-100，默认 50
性格倍率: 1.1（增幅项）/ 1.0（无关项）/ 0.9（削减项）

HP   = round((种族HP  × 1.7 + 个体值 × 0.85 + 70) × 性格倍率 + 100)
其他 = round((种族值   × 1.1 + 个体值 × 0.55 + 10) × 性格倍率 + 50)
```

此为 PVP 基础公式。星级对六维的数值影响未确认，勿编造。

**注意性格倍率不是固定值**：削减项固定为 −10%（×0.9），但**提升项为 +10% ~ +20%，随突破成长**。上式中的「性格倍率 = 1.1」只是**未突破时的下限**，满突破时增幅项应取 ×1.2。因此按 1.1 算出的实际属性是下限值，回答时应说明这一点，不要把它当作唯一答案。

### 2.3 性格（30 种）

- 提升幅度：**+10% ~ +20%**（随突破成长）
- 削减幅度：固定 **−10%**

### 2.4 天分（个体值）

每只精灵随机获得 1~3 条个体值加成：

| 天分等级 | 加成条数 | 每条加成 |
|----------|:--------:|:--------:|
| 一般般 | 1 | +7~10 |
| 还不错 | 2 | +7~10 |
| 相当好 | 3 | +7~10 |
| 了不起 | 3（全 +10） | +10 |

- 「了不起」必须有一条与性格增幅项重叠
- **适格之钥**可更改天分位置，**能力砥石**可提升至 +10
- PVP 中天分与性格均保留生效

| 维度 | 规则 |
|------|------|
| 等级 | 战斗 / 经验果实 / 家园锻炼提升；魔法师 40 级时精灵上限 50 级 |
| 升星 | 共 5 星，每星 10 段，消耗魔法粉尘逐段提升；**PVP 自动满星** |
| 突破 | 提升性格增幅项的幅度（+10% → 最高 +20%） |
| 觉醒 | 见下方 2.6 |

### 2.6 觉醒

前置条件：精灵 **60 级 + 5 星**解锁觉醒，最多觉醒 **5 次**。

**加成仅 PVE 生效，PVP 与星光对决中无效。**

每觉醒 1 次获得（**逐层线性累加，不是乘算**）：

| 项目 | 每层 | 说明 |
|------|:----:|------|
| 本系伤害强化 | +15% | 同系技能增伤；双属性精灵的两种属性都生效 |
| 系别极化 | +45% | 克制对手时伤害更高；攻击被抵抗的目标时，削弱对方的抵抗减伤 |
| 系别钝化 | +45% | 自身被克制时降低受到的伤害；对手攻击被我方抵抗时，进一步减少受伤 |

累计加成：

| 觉醒次数 | 本系伤害强化 | 系别极化 | 系别钝化 |
|:--------:|:------------:|:--------:|:--------:|
| 0 | 0% | 0% | 0% |
| 1 | 15% | 45% | 45% |
| 2 | 30% | 90% | 90% |
| 3 | 45% | 135% | 135% |
| 4 | 60% | 180% | 180% |
| 5（满觉醒） | **75%** | **225%** | **225%** |

注意：觉醒加成的是**伤害与减伤的百分比**，不是六维种族值。觉醒对六维数值的影响未确认，勿编造。

## 三、伤害系统

### 3.1 核心公式

```
伤害 = floor(
    (攻击方实际攻击力 / 防御方实际防御力)
    × (37/41)                 ≈ 0.9024，固定常数
    × 威力
    × 属性克制                 加算，双克制为 3
    × 本系加成                 1.25
    × 特性倍率
    × 其他倍率
    × (1 - 减伤%)
    × 连击数
)
```

物理技能用物攻对物防，魔法技能用魔攻对魔防。伤害无波动、无暴击、不受等级影响，可精确计算。

### 3.2 星陨伤害

```
星陨威力 = 层数² + 24 × 层数 - 24
星陨伤害 = floor((攻/防) × 37/41 × 星陨威力 × 幻系克制 × (1 - 减伤%))
```

- 使用**非幻系**技能攻击时触发，消耗全部层数
- 幻系技能不触发星陨
- 星陨属于负面印记

### 3.3 灼烧伤害

```
每层灼烧 = 敌方最大HP × 2%
PVP 上限按 1000 血量计算（即每层最多 20 点伤害）
回合中触发 = 真实伤害（不受属性克制）
回合结束触发 = 受属性克制影响
衰减 = 回合结束时衰减一半层数（向上取整）
火系精灵免疫
```

## 四、能量系统

| 项目 | 规则 |
|------|------|
| 能量上限 | 10（特殊情况除外） |
| 初始能量 | 10 |
| 回能手段 | 每只精灵自带「聚能」：0 能耗，变化技能，回复 **5** 能量 |
| 技能能耗 | 0 ~ 30 不等 |
| PP | 不存在，全部改为能量消耗 |

「聚能」被视作**状态类技能**，会触发对手攻击型技能的「应对」效果。
能量可被回复、消耗、被对方偷取。

## 五、魔力值系统

独立于精灵 HP 的**全局团队资源**，相当于队伍的「命数」：

| 项目 | 规则 |
|------|------|
| 初始值 | 双方各 4 点 |
| 扣除 | 每阵亡 1 只精灵，扣 1 点 |
| 胜负判定 | 魔力值归零 → **立即判负** |

即使还有 6 只存活精灵，魔力值剩 1 点时再阵亡 1 只即败。

## 六、技能系统

### 6.1 分类

物理(172) / 魔法(133) / 变化(189)，共 **494** 个技能。伤害类型由技能分类决定。

### 6.2 「应对」三角克制闭环

游戏核心是**攻击 → 状态 → 防御 → 攻击**的三角：

| 技能类型 | 克制对象 | 克制效果 |
|----------|----------|----------|
| 攻击型 | 状态型 | **1.5 倍**伤害 + 附加效果（如打断） |
| 状态型 | 防御型 | 破防，可使目标昏迷、增加技能能耗等 |
| 防御型 | 攻击型 | 高额减伤 + 反制效果，成功后获得「先手 +1」 |

**「应对」机制定义**：当技能指定的「应对」类型与对手当回合释放的技能类型匹配时，**本回合必定先释放应对技，再释放被应对的技能**。绝大多数应对技在应对成功时产生额外效果。

战术口诀：遇状态用攻击（1.5 倍 + 打断）→ 遇防御用状态（破防 + 控制）→ 遇攻击用防御（减伤 + 抢下回合先手）。

### 6.3 技能标签

| 标签 | 数量 | 说明 |
|------|:----:|------|
| 应对攻击 | 48 | 被攻击时触发不同效果 |
| 应对防御 | 26 | 对手防御时触发不同效果 |
| 先手 | 9 | ±1，改变行动顺序；防御技格挡成功后可获先手 +1 |
| 蓄力 | 8 | 本回合蓄力不释放，下回合再次选择该技能才正式释放（高风险高回报） |
| 脱离 | 12 | 主动下场，触发入场效果 |
| 传动 | 11 | 技能在 1-4 号位间每回合移动 |
| 迅捷 | — | 主动换精灵入场时立刻自动释放该技能，不占用回合 |
| 折返 | — | 离开战场回背包，换一只非自己的精灵入场 |
| 连击 | — | 以相同威力造成 X 次伤害，每段均可触发吸血/印记 |
| 吸血 | — | 造成伤害的一部分回复自身生命 |
| 迸发 | — | 精确触发条件未确认 |
| 巧变 | — | 技能转换规则未确认 |

标签联动：

| 组合 | 战术价值 |
|------|----------|
| 折返 + 迅捷 | 折返换人 → 换上带迅捷技能的精灵 → 入场立刻释放，无缝衔接 |
| 连击 + 吸血 | 每段伤害均触发吸血，回血效率翻倍 |
| 迅捷 + 连击/吸血 | 入场即发动连击或吸血，实现突袭或紧急回血 |

### 6.4 天气

| 天气 | 效果 |
|------|------|
| 暴风雪 | 每回合为非冰系叠加 1 层冻结（每层 = 5% 最大HP），HP% < 冻结层数时强制退场；冰系免疫 |
| 沙暴 | 地系技能能耗 -2、地系伤害 +15%、双防 +10%；非免疫精灵每回合损失 5% 最大HP |
| 雨天 | 水系技能威力 **+75%**（S2「落雨」调整后；调整前为 +50%） |

通用规则：

- **全场生效**，对敌我双方同时生效
- 持续 **8 回合**后自动消退
- 天气只能被新天气覆盖，不能被「环境」类技能覆盖，反之亦然
- PVE 首领战可能锁定特殊天气（星云 / 陨石 / 迷雾等）

## 七、异常状态

| 状态 | 施加技能数 | 每层效果 | 衰减 | 触发时机 |
|------|:----------:|------|:----:|------|
| 灼烧 | 8 | **2%** 最大HP 火系伤害 | 每回合减半（向上取整） | 回合结束 |
| 中毒 | 17 | **3%** 最大HP 毒系伤害 | 不衰减 | 回合结束 |
| 冻结 | 12 | **5%** 最大HP；HP% < 冻结% → 直接力竭 | — | 实时判定 |
| 星陨 | 11 | 非幻系技能攻击时消耗全部层数造成额外幻系伤害 | 一次性消耗 | 攻击时 |
| 萌化 | 9 | 退化到进化链上一阶，种族值同步降低 | — | 即时 |
| 寄生 | 1 | **6%** 最大HP 吸取（草系免疫） | — | 回合结束 |

细节：

- **冻结**替代了旧版麻醉/冰冻/睡眠等硬控。血条上显示冻结标记；当精灵当前 HP 百分比 < 被冻结比例时直接力竭。本质是血量阈值判定击杀，**不是跳过回合的控制**。
- **萌化**使精灵变为进化链上一阶形态（如三阶 → 二阶），种族值同步降为上一阶；若已是初始形态则无法萌化。萌系精灵萌化时可清除自身所有负面效果。
- **中毒 vs 灼烧**：中毒 3%/层/回合、不衰减，适合长期消耗；灼烧单层伤害更高但会衰减，适合短期爆发。

## 八、印记系统

### 8.1 核心规则

**每方最多同时存在 1 个正面印记 + 1 个负面印记**，新印记覆盖同类型旧印记。

- 印记**常驻战场**，不随精灵下场而清除
- 正面印记与负面印记互不影响，各自独立遵守「最多 1 个」规则
- 区别于此：增益/减益在精灵**下场后立即清除**

| 名称 | 系别 | 效果 |
|------|------|------|
| 湿润印记 | 水 | 全技能能耗 -1 |

| 风起印记 | 翼 | 先手攻击时，技能威力 +20% |
| 光合印记 | 草 | 回合结束时获得 1 能量 |
| 攻击印记 | 普通 | 全技能威力 +10% |
| 萌芽印记 | — | 获得增益时，额外获得 1 层 |
| 迟缓印记 | 地 | 后手攻击时，本次威力 +30% |
| 龙噬印记 | 龙 | 释放高能耗技能时双攻提升，可叠加（阈值与倍率未实测确认） |
| 蓄电印记 | 电 | 入场首回合技能威力 +10%（具体表述未实测确认） |

### 8.3 负面印记

| 名称 | 系别 | 效果 |
|------|------|------|
| 减速印记 | 冰 | 速度 -10 |

| 星陨印记 | 幻 | 使用非幻系技能攻击时触发，消耗全部层数造成额外幻系伤害，可叠加 |

### 8.4 覆盖规则的例外

- 具备印记清除能力的技能：「倾泻」（普通系）、「焚烧烙印」（火系）

## 九、血脉系统

血脉的作用是**更改精灵的血脉属性**，从而改变可用的血脉技能。

- 每只精灵可更换血脉类型（18 种属性各一种）
- 更换血脉后获得该属性对应的血脉技能
- 不同精灵换相同血脉，得到的技能组合不同
- 血脉技能池共 **81 个**独特技能
- 注意：**没有「血脉魔法」这一分类**

### 战前二选一：进化之力 / 愿力冲击

对战前需为**整场比赛**选择携带其一：

| 名称 | 次数 | 冷却 | 效果 |
|------|:----:|:----:|------|
| 进化之力 | 1 次 | 无 | 对首领血脉精灵使用，本场战斗中进化，部分精灵激活远古血脉 |
| 愿力冲击 | 2 次 | 2 回合 | 将精灵**首个技能**变为 80 威力「冲击」。属性由**副血脉**决定（双同属性如翼王则用主属性）；物攻/魔攻取精灵更高项。**核心：应对状态类技能时伤害提升 150%**（等效 230 威力），配合属性克制可实现逆属性秒杀 |

## 十、精灵特性（被动）

375 只精灵均有特性文本，**100% 覆盖**。

**重要：任何具体精灵的特性文本必须调用精灵信息查询工具获取，不得凭本手册推断。** 本手册只描述特性的设计类别，不记录任何精灵与特性的对应关系。反过来，被问到「哪只精灵拥有某个特性」时，也必须通过工具检索确认，不要猜测。

特性大致分为以下类别：

| 类别 | 效果 |
|------|------|
| 技能威力递增 | 每次释放技能后，下次技能威力提升 |
| 技能回血 | 释放技能后按技能威力比例恢复 HP |
| 能耗削减 | 释放技能后降低下次技能能耗 |
| 异常附加 | 技能命中时概率施加异常状态 |
| 阵亡联动 | 每损失一只己方精灵，自身能力提升 |
| 系别增益 | 按掌握的技能属性数量或队伍属性构成提升能力 |
| 克制联动 | 造成克制伤害后获得增益或回复能量 |
| 魔力干涉 | 击杀或阵亡时额外影响双方魔力值 |
| 萌化清除 | 萌化时清除自身所有负面效果 |

各系别的特性设计方向：

| 系别 | 方向 |
|------|------|
| 幻 | 星陨降低对面全体属性 |
| 萌 | 萌化让对面退化 |
| 虫 | 共享 buff（队伍虫系精灵共享增益） |
| 恶 | 吸血恢复 |
| 幽灵 | 增加对面能量消耗 |
| 翼 | 先手出招，速度最快 |
| 武 | 全能型，见招拆招 |
| 毒 | 长时间毒素消耗 |
| 电 | 开场获额外增益，电系越多 buff 越强 |
| 龙 | 高爆发，蓄力越长伤害越高 |
| 冰 | 冻结控制 + 削减对面属性 |
| 地 | 高防御持久战 |
| 光 | 融合属性，队伍属性越多能力越强 |
| 水 | 减少能耗，高频释放技能 |
| 草 | 回血 + 恢复能量 |
